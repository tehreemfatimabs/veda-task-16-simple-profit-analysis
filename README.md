# VEDA Technology – Task 16: Simple Profit Analysis

## Project Overview
This project focuses on analyzing profitability across different product categories using Microsoft Excel and the Superstore dataset.

## Objective
To compare total and average profit across product categories and identify the most and least profitable categories.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis

## Analysis Performed
- Grouped profit data by product category.
- Calculated total profit for each category.
- Calculated average profit for each category.
- Compared profitability across categories.
- Created a column chart to visualize total profit.

## Key Findings
- **Highest Total Profit:** Technology
- **Lowest Total Profit:** Furniture
- **Highest Average Profit:** Technology

## Business Insights
Technology demonstrates the strongest profitability based on both total and average profit.

Furniture generates the lowest total profit, indicating an opportunity for further investigation into its profitability.

## Deliverables
- Excel profit analysis workbook.
- Category-wise profit summary.
- Profit comparison chart.
